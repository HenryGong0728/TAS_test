# doc 文件夹说明

本文件夹用于 **Git 仓库协作考核**，请按考核流程在此目录下完成文件操作：

1. **云端修改**：在仓库主分支的 `doc/` 文件夹中新建文件，保存并提交修改。
2. **本地修改**：在本地项目的 `doc/` 文件夹中新建文件，填写任意可追踪内容（如个人介绍、考核笔记），完成后提交并推送到远程个人分支。

## 注意事项

- 提交说明（Commit Message）需明确描述本次修改内容，例如：

  ```text
  docs: 新增个人考核测试文件
  ```

- 禁止直接在主分支上进行开发，请先创建个人分支。
- 所有修改需保证可追踪、可同步。
